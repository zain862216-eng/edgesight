The problem

Most computer vision tools need a GPU server, a paid API, or a fast internet link. Students, small clinics, farms and schools in low-connectivity regions often have none of these, and sending photos to a remote server also raises privacy concerns.

Our solution

Runs on the device

Image processing happens on the user's own browser, so photos never leave their device.

Serverless by design

Just static files on Amazon S3 behind CloudFront. Nothing to patch, scale or keep running.

OpenCV-style pipeline

Grayscale, blur, edge detection and thresholding, the core building blocks of vision apps.

Works offline

Once loaded, the tool keeps working with no connection at all.

Live demo

Choose a photo to begin. A sample image is shown until then.

Architecture

Browser (HTML + JS)→ Amazon CloudFront→ Amazon S3 static hosting

All vision processing is done client-side, so there is no backend, database or physical server to run.
